# 🚀 My Personal Portfolio

This is my first professional portfolio project, developed to centralize my projects, skills, and contact information in an elegant and responsive way.

---

## 💻 About the Project
The goal is to create a virtual showcase that demonstrates my evolution as a Front-End developer. The website will feature an introduction section, a project gallery, technical skills, and a contact form.

## 🛠 Technologies Used
*   **HTML5:** Semantic structuring for better SEO and accessibility.
*   **CSS3:** Modern styling using Flexbox/Grid and animations.
*   **JavaScript:** DOM manipulation for interactivity (e.g., mobile menu, smooth scroll).
